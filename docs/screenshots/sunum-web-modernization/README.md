# Sunum Web görsel karşılaştırmaları

Görüntüler, aynı ders adımı ve **1920×1080** sunum tuvalinde gerçek Google Chrome ile alınmıştır. Her PNG'de solda depodaki önceki CSS, sağda bu çalışmadaki CSS bulunur. Karşılaştırma sayfası yalnızca çekim etiketlerini ve iki ekran görüntüsünü yan yana yerleştirir.

| 3 | Hayalî Mülakat, s.214 — puanlama rubriği |
| 4 | Tiyatro Metnini Canlandırma, s.281 — değerlendirme kontrol listesi |
